# Kaaphalla Hub

Live hub (chests, map, portals, feed, history, to-do) for the Kaaphalla Valheim server: https://adriaanfox.github.io/chest-finder/

- `index.html` – the whole site (search, wall map, fill levels, changes, craft list, map with portals).
- Live data (`wall.json`, `map.txt`, `height.txt`) comes from a secret Gist that the server updates every 2 minutes.
